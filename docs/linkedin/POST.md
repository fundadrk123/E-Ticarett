## Carousel Yükleme



1. LinkedIn → **Gönderi oluştur**

2. Metni yapıştır

3. Görsel ekle → `LinkedIn-Carousel/` klasöründeki PNG'leri sırayla yükle (01 → 09)

4. **Paylaş**
